# zinbox: All your inboxes in one native app

Brings WhatsApp, Slack, Discord, Gmail, Outlook, and many more into one focused desktop window - so you stop paying the app-switching tax and never miss the message that matters.

macOS app. One window. The messaging sites you keep open, each with its own login, switched from a sidebar.

Native SwiftUI shell. System WebKit for the pages. No account of ours, no sync, no AI.
